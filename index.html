📚 교육서

1. 팀 운영 규칙 (5가지)
  1. 모든 결정은 대장 승인 후 실행. 결제·계약·외부 발송·삭제는 절대 혼자 하지 않아요.
  2. 지시는 티켓 하나에 하나씩. 제목에 결과물이 보이게 적어요. (예: "카페 오픈 체크리스트 v1")
  3. 모르면 '확인 필요'로 남기기. 추측으로 채우지 않고, 대장에게 물어볼 것을 3개 이내로 정리해요.
  4. 결과는 한 번에 하나. 초안 → 검수 → 완료 순서로, 검수 전에 다음 단계로 넘어가지 않아요.
  5. 기록은 단톡방에. 대화로 끝난 일도 티켓에 한 줄 남겨야 다음에 이어져요.
2. 비서별 보고 양식

모든 비서는 같은 뼈대(결론 → 한 일 → 확인 필요 → 다음 단계)로 보고해요. 맡은 일에 따라 강조점만 달라요.

3. 단톡방 사용법
  1. 담당을 고르고 메시지를 적어 보내기. 티켓이 새로 열리고 상태는 보통 대기로 시작해요.
  2. 한 티켓에 이어 말하려면 말풍선 위 전체보기로 들어가 답글을 남겨요. 상태가 작업 중으로 바뀝니다.
  3. 결과가 마음에 들면 완료. 마음에 안 들면 이유를 적어 다시 대기로 돌려요.
  4. 오피스 좌석 맵에서 팀원을 누르면 그 팀원에게 바로 말을 걸거나 연결 문구를 복사할 수 있어요.
4. 실시간 DB · 텔레그램 연결 방법
  1. Apps Script: script.new → Code.gs·appsscript.json 붙여넣기 → 배포 → 새 배포 → 웹 앱, 실행 계정 나, 액세스 모든 사용자 → 나온 /exec 주소 복사.
  2. 우측 상단 ⚙️ 설정 → 실시간 DB에 주소를 붙여넣고 저장하고 동기화. 폰·PC가 같은 내용을 보고, 15초마다 새 내용을 확인해요.
  3. 텔레그램: 봇(@Pinky_office_bot)에게 /start를 보낸 뒤 설정에서 자동 연결. Chat ID를 알아서 찾고 웹훅까지 걸어요.
  4. 단톡방에 새 지시가 올라오면 텔레그램으로 알림이 와요. 그 알림에 답장하면 같은 티켓에 답글로 달립니다.
  5. n8n도 그대로 쓸 수 있어요: Webhook 노드(POST) → 주소를 설정의 Webhook URL에 저장. (본문: { type, office, chief, to, title, message, status, createdAt, text })
5. 자주 하는 실수
  • 한 티켓에 여러 가지 일을 몰아넣기 → 결과가 섞여요. 쪼개서 보내세요.
  • 완료 처리를 안 하기 → "작업 중"이 계속 쌓여 오늘 상태가 안 보여요.
  • 데모 모드를 켜 둔 채로 실제 일을 하기 → ⚙️ 설정에서 끄면 예시 데이터가 숨겨져요.
