📚 교육서

1. 팀 운영 규칙 (5가지)
  1. 모든 결정은 대장 승인 후 실행. 결제·계약·외부 발송·삭제는 절대 혼자 하지 않아요.
  2. 지시는 티켓 하나에 하나씩. 제목에 결과물이 보이게 적어요. (예: "카페 오픈 체크리스트 v1")
  3. 모르면 '확인 필요'로 남기기. 추측으로 채우지 않고, 대장에게 물어볼 것을 3개 이내로 정리해요.
  4. 결과는 한 번에 하나. 초안 → 검수 → 완료 순서로, 검수 전에 다음 단계로 넘어가지 않아요.
  5. 기록은 회의실에. 대화로 끝난 일도 회의실 티켓에 한 줄 남겨야 다음에 이어져요.
2. 비서별 보고 양식

모든 비서는 같은 뼈대(결론 → 한 일 → 확인 필요 → 다음 단계)로 보고해요. 맡은 일에 따라 강조점만 달라요.

3. 회의실(우편함) 사용법
  1. 담당을 고르고 제목·내용을 적어 지시 보내기. 상태는 보통 대기로 시작해요.
  2. 비서가 답하면 회의실 카드에서 답글로 기록하고 상태를 작업 중으로 바꿔요.
  3. 결과가 마음에 들면 완료. 마음에 안 들면 이유를 적어 다시 대기로 돌려요.
4. 텔레그램 · n8n 연결 방법
  1. n8n: 새 워크플로 → Webhook 노드 → Method POST → 만든 URL 복사.
  2. 우측 상단 ⚙️ 설정 → 자동화 연결에 URL을 붙여넣고 저장, 테스트 전송으로 확인해요.
  3. Webhook 뒤에 Telegram 노드를 붙이면 회의실 지시가 텔레그램으로 와요. (본문의 text 필드를 쓰면 돼요)
  4. 전송 본문: { type, office, chief, to, title, message, status, createdAt, text }
  5. 브라우저 보안(CORS) 때문에 사이트에서 직접 못 보내는 경우가 있어요. 그때는 n8n Webhook 노드의 Allowed Origins에 이 사이트 주소를 추가해 주세요.
5. 자주 하는 실수
  • 한 티켓에 여러 가지 일을 몰아넣기 → 결과가 섞여요. 쪼개서 보내세요.
  • 완료 처리를 안 하기 → "작업 중"이 계속 쌓여 오늘 상태가 안 보여요.
  • 데모 모드를 켜 둔 채로 실제 일을 하기 → ⚙️ 설정에서 끄면 예시 데이터가 숨겨져요.
